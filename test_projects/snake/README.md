# 🐍 Snake Game

A classic Snake game built with Python using the built-in `tkinter` library — no external dependencies required.

## Requirements

- Python 3.x (tkinter is included with standard Python installations)

## How to Run

```bash
python test.py
```

## Controls

| Key | Action |
|-----|--------|
| `↑` / `W` | Move Up |
| `↓` / `S` | Move Down |
| `←` / `A` | Move Left |
| `→` / `D` | Move Right |
| `R` | Restart (after game over) |

## Gameplay

- Guide the snake to eat the red food pellets to grow and earn points.
- Each food pellet eaten is worth **10 points**.
- The game ends if the snake hits a wall or runs into itself.
- Your **high score** is tracked for the session.

## Features

- Dark-themed window with a subtle grid
- Score and high score HUD
- Smooth directional controls (WASD + arrow keys)
- Game over overlay with restart prompt
